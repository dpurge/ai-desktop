# Concise summary

Use this when the user asks for a summary, recap, or "tl;dr".

1. Write at most 5 bullets, each under 20 words.
2. Lead with the main point or decision; put details after it.
3. Keep names, numbers, and dates exactly as given.
4. List open questions or next steps last, only if there are any.
5. Do not add opinions or facts that are not in the source.
